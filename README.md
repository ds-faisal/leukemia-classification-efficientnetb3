# leukemia-classification-efficientnetb3
First-Author Publication (2025): Automated screening pipeline for hematologic malignancies using EfficientNetB3.

# Overview 
Reproducible code for my first-author paper on Acute Lymphoblastic Leukemia (ALL) classification. Utilizes EfficientNetB3 with mixed-precision training and One-Cycle Policy to mitigate overfitting on limited medical datasets. Prioritizes MCC and F2-Score for imbalanced clinical data.
